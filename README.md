# BreakTrack — ระบบตรวจจับและแจ้งเตือนการพักเกินเวลาของพนักงาน

> เว็บแอปพลิเคชันแบบ Full Stack ที่ใช้ Computer Vision ตรวจจับพนักงานในห้องพัก
> นับเวลาพักสะสมรายบุคคล และแจ้งเตือนหัวหน้าแผนกแบบเรียลไทม์เมื่อพักเกินเวลาที่กำหนด

โครงงานรายวิชาเตรียมสหกิจศึกษา · ภาควิชาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยสงขลานครินทร์

---

## ปัญหาที่แก้

องค์กรกำหนดเวลาพักไว้ชัดเจน แต่ไม่มีเครื่องมือที่ตรวจสอบได้จริงว่าพนักงานคนใดพักเกินกำหนด
หัวหน้าแผนกต้องคอยสังเกตด้วยตนเองตลอดเวลา ซึ่งเป็นภาระและไม่แม่นยำ

**BreakTrack** ทำให้กระบวนการนี้เป็นอัตโนมัติ โดยหัวหน้าแผนกจะได้รับแจ้งเตือนทันทีเมื่อมีพนักงานพักเกินเวลา

---

## ภาพรวมสถาปัตยกรรม

```
   กล้อง (Webcam)
        │  เฟรมภาพ
        ▼
┌──────────────────────────────────────────┐
│  Backend (FastAPI)                       │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │ โมดูลตรวจจับ                        │  │
│  │  1. YOLOv8  → "เป็นลูกบอลไหม"       │  │
│  │  2. OpenCV  → "สีอะไร" (HSV)        │  │
│  │     ต้องผ่านทั้ง 2 ข้อ (AND)        │  │
│  └────────────────────────────────────┘  │
│                  │                       │
│                  ▼                       │
│  เทียบสี → รหัสพนักงาน → นับเวลาพัก      │
│                  │                       │
└──────────────────┼───────────────────────┘
         │         │              │
    SQL  │    WebSocket      MJPEG Stream
         ▼         ▼              ▼
   PostgreSQL   Frontend (React)
```

**หลักการออกแบบ:** โมเดล AI ทำหน้าที่ระบุ *ชนิดของวัตถุ* ส่วนการประมวลผลภาพแบบดั้งเดิม
ทำหน้าที่อ่าน *คุณสมบัติ* (สี) — เพราะโมเดล pretrained ไม่มีแนวคิดเรื่องสี
การใช้เงื่อนไขร่วมกันทั้งสองชั้นช่วยลดการตรวจจับผิดพลาดที่อาจทำให้พนักงานถูกแจ้งเตือนโดยไม่เป็นธรรม

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี | เหตุผลที่เลือก |
|---|---|---|
| Frontend | React 19 + Vite + React Router | หน้าจอต้องอัปเดตข้อมูลตลอดเวลา เหมาะกับการแบ่งเป็น component |
| Backend | FastAPI + Uvicorn | ภาษาเดียวกับโมเดล AI เรียกใช้ในโปรเซสเดียวได้ รองรับ WebSocket ในตัว |
| Database | PostgreSQL + SQLAlchemy | ข้อมูลมีความสัมพันธ์ชัดเจน (พนักงาน ↔ แผนก ↔ ประวัติการพัก) |
| Realtime | WebSocket | ต้องแจ้งเตือนทันที ไม่ใช่รอผู้ใช้กดรีเฟรช |
| Auth | JWT + bcrypt | ยืนยันตัวตนแบบ stateless และเก็บรหัสผ่านแบบถอดกลับไม่ได้ |
| Computer Vision | YOLOv8n (pretrained) + OpenCV | ตรวจจับวัตถุโดยไม่ต้องฝึกโมเดลใหม่ + วิเคราะห์สีในระบบ HSV |

## ฟีเจอร์

### ระบบตรวจจับ
- ตรวจจับวัตถุด้วย YOLOv8 (pretrained) ร่วมกับการจำแนกสีในระบบ HSV
- นับเวลาพักสะสม **เฉพาะช่วงที่ตรวจพบพนักงานในพื้นที่จริง**
- สตรีมภาพจากกล้องขึ้นหน้าเว็บพร้อมกรอบแสดงผลการตรวจจับ

### ระบบผู้ใช้งานและสิทธิ์ (RBAC)
- ผู้ใช้งาน 2 ระดับ: **ผู้ดูแลระบบ (Admin)** และ **หัวหน้าแผนก (Supervisor)**
- **แยกข้อมูลตามสิทธิ์จริงที่ฝั่งเซิร์ฟเวอร์** — หัวหน้าแผนกเห็นข้อมูลเฉพาะแผนกตนเองเท่านั้น
  (ไม่ได้ซ่อนแค่ที่หน้าจอ แต่กรองก่อนส่งข้อมูลออกจาก backend)
- กติกา: หัวหน้าแผนกมีได้แผนกละ 1 คน — บังคับทั้งที่ฝั่งเซิร์ฟเวอร์และตัดตัวเลือกออกจากหน้าจอ
- Safeguard: ลบบัญชีตนเองไม่ได้ และลบผู้ดูแลระบบคนสุดท้ายไม่ได้

### การจัดการข้อมูล
- จัดการข้อมูลพนักงาน: เพิ่ม / แก้ไข / ลบ (เฉพาะ Admin)
- จัดการบัญชีผู้ใช้งาน: เพิ่ม / ลบ (เฉพาะ Admin)
- กำหนดสีประจำตัวพนักงานเพื่อใช้ระบุตัวตน

### หน้าจอ
| หน้า | รายละเอียด |
|---|---|
| ภาพรวม | สรุปจำนวนพนักงานในพื้นที่พัก เวลาเฉลี่ย และรายการแจ้งเตือน |
| รายชื่อพนักงาน | ตารางพนักงานพร้อมสถานะปัจจุบัน + จัดการข้อมูล |
| กล้องเรียลไทม์ | ภาพสดจากกล้องพร้อมผลการตรวจจับ |
| การแจ้งเตือน | รายการพนักงานที่พักเกินเวลา |
| จัดการผู้ใช้งาน | จัดการบัญชีเข้าระบบ (เฉพาะ Admin) |

## การติดตั้งและใช้งาน

### สิ่งที่ต้องมี
- Python 3.11+
- Node.js 18+
- PostgreSQL 17
- เว็บแคม

### 1. ตั้งค่าฐานข้อมูล
```bash
# สร้างฐานข้อมูล
psql -U postgres -c "CREATE DATABASE breaktrack;"
```

### 2. ตั้งค่า Backend
```bash
cd backend
pip install -r requirements.txt
```

> หมายเหตุ: `ultralytics` จะดึง PyTorch มาให้อัตโนมัติ
> หากมีการ์ดจอ NVIDIA และต้องการใช้ GPU ให้ติดตั้ง PyTorch เวอร์ชัน CUDA เพิ่มตาม [คู่มือทางการ](https://pytorch.org/get-started/locally/)

สร้างไฟล์ `backend/.env`:
```
DATABASE_URL=postgresql://postgres:<รหัสผ่าน>@localhost:5432/breaktrack
JWT_SECRET_KEY=<สตริงสุ่มความยาว 64 ตัวอักษร>
JWT_ALGORITHM=HS256
```

ใส่ข้อมูลตั้งต้นและเริ่มเซิร์ฟเวอร์:
```bash
python seed.py
python -m uvicorn main:app --reload
```

### 3. ตั้งค่า Frontend
```bash
cd frontend
npm install
npm run dev
```

เปิด `http://localhost:5173`

## การตั้งค่า

แก้ไขได้ที่ `backend/config.py`

| ค่า | ความหมาย |
|---|---|
| `COLOR_RANGES` | ช่วงค่าสี HSV ของแต่ละสีที่ใช้ระบุตัวตน |
| `MIN_SATURATION` / `MIN_VALUE` | เกณฑ์ความสด/ความสว่างขั้นต่ำของสี |
| `MAX_BREAK_MINUTES` | เวลาพักสูงสุดก่อนแจ้งเตือน (ค่าเริ่มต้น 15 นาที) |
| `TIME_SCALE` | ตัวคูณเร่งเวลาสำหรับทดสอบ (`1` = เวลาจริง, `60` = ทดสอบเร็ว 60 เท่า) |
| `BALL_CONFIDENCE_THRESHOLD` | ความมั่นใจขั้นต่ำที่ YOLO จะยืนยันว่าเป็นวัตถุเป้าหมาย |

## ข้อจำกัดที่ทราบ

โครงงานนี้เป็นระบบต้นแบบ (Prototype) จึงมีขอบเขตดังนี้

- **ระบุตัวตนด้วยสี ไม่ใช้การจดจำใบหน้า** — เนื่องจากข้อมูลใบหน้าเป็นข้อมูลชีวภาพที่มีความอ่อนไหวตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล จึงจำแนกได้สูงสุดตามจำนวนสีที่แยกความแตกต่างได้ชัดเจน (ประมาณ 7-8 สีต่อกล้อง 1 ตัว)
- **ความแม่นยำขึ้นกับสภาพแสง** — การวิเคราะห์สีในระบบ HSV ทนต่อการเปลี่ยนแสงได้ระดับหนึ่ง แต่ยังต้องปรับค่าเกณฑ์ให้เหมาะกับสภาพแสงของสถานที่ใช้งานจริง
- **เวลาพักสะสมเก็บในหน่วยความจำ** — ตาราง `break_sessions` ถูกออกแบบไว้แล้วแต่ยังไม่ได้บันทึกประวัติถาวร (เป็นงานต่อยอด)
- **JWT ยังไม่รองรับการเพิกถอนก่อนหมดอายุ** — token มีอายุ 8 ชั่วโมง
- **รองรับกล้อง 1 ตัว / ห้องพัก 1 จุด** — ยังไม่ครอบคลุมหลายพื้นที่พร้อมกัน

- บันทึกประวัติการพักลงฐานข้อมูลเพื่อทำรายงานย้อนหลัง

- รองรับกล้องหลายตัวและหลายพื้นที่พร้อมกัน
